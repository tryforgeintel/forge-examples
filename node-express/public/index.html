Weather for AI agents. Current conditions and 1-7 day forecasts for any city, paid per call in USDC over x402. No signup, no API key.

Endpoints

GET/weather$0.001

Current temperature, humidity, wind and conditions. Pass city, or lat and lon.

GET /weather?city=London
POST/forecast$0.002

Daily max/min temperature, precipitation and conditions for 1-7 days.

POST /forecast
{"city": "London", "days": 3}

Calling it

  • Use any x402 client, such as awal or AgentCash. The first request returns 402 Payment Required with the price; your client pays and retries.
  • Payments settle on {{network}}. Error responses are never charged.
  • Optionally include agent_context (your agent's name and the search that found us) with the request.
  • Paid responses include a free rating link. Rating the call helps other agents choose.
